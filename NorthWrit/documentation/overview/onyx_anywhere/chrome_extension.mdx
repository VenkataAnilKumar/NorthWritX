Use the NorthWrit Chrome extension to ask NorthWrit from any web page. You can also replace your new-tab page with NorthWrit.

Features include:

- NorthWrit on every new tab
- NorthWrit as a side panel on any page
- Search or ask about selected text
- Ask about the page you are reading
- Search from the address bar

<Note>
  The extension works with NorthWrit Cloud and with self-hosted NorthWrit on all editions. It uses your normal NorthWrit sign-in.
  It does not store a separate credential.
</Note>

## Getting Started

**For NorthWrit Cloud users**: Install the extension from the Chrome Web Store.

**For self-hosted users**: Your administrator provides the extension and the URL of your NorthWrit server. On first launch,
the extension opens a welcome page. Enter your NorthWrit URL if your administrator has not pre-set it.

## Using the Extension

### **Side Panel**

- Select **Read this tab** to let NorthWrit open the current page and use it as context for your question

### **Selection Search**

- Highlight text on a web page
- Click the NorthWrit icon that appears, or right-click and choose the NorthWrit menu item
- NorthWrit opens with the selected text as your prompt

### **Address Bar**

- Type `onyx`, press `Tab`, then type your question
- Press `Enter` to open the answer in NorthWrit chat

### **Shortcuts**

- **Mac**: `Cmd+Shift+O` to toggle the new-tab page, `Ctrl+O` to open the side panel
- **Windows**: `Ctrl+Shift+O` to toggle the new-tab page, `Alt+O` to open the side panel
- **Linux**: `Ctrl+Shift+O` to toggle the new-tab page, `Ctrl+O` to open the side panel

You can change these shortcuts at `chrome://extensions/shortcuts`.

## Settings and Options

Click the NorthWrit icon in the Chrome toolbar and select **Extension Settings** (or right-click the icon and select
**Options**). Set the **Root Domain** of your NorthWrit server.
Turn **Use NorthWrit as new tab page** and **Use NorthWrit in Address Bar** on or off.

<Info>
  If your administrator manages the extension with a browser policy, the NorthWrit URL and the new-tab setting can be locked.
</Info>
