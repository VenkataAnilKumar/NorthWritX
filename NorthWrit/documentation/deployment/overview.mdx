## Deployment Modes

NorthWrit supports two deployment modes:

**NorthWrit Standard** — The full NorthWrit platform, recommended for serious users and larger teams.
Includes everything in Lite plus:
- Vector + Keyword index for RAG
- Background containers for syncing knowledge from connectors
- AI model inference servers for deep learning models used during indexing and inference
- File storage in the object store
- Performance optimizations via Redis

**NorthWrit Lite** — A lightweight Chat UI that uses fewer resources tha NorthWrit Standard.
It is great for users who want to try NorthWrit quickly or teams only interested in Chat and Agents. Includes LLM chat,
tools, file uploads, and Projects, but does not use the vector database or background workers.
Docker Compose Lite skips both model servers;
Helm Lite still starts the inference model server unless you disable it explicitly.

<Note>
  NorthWrit Lite does not include indexing. Use NorthWrit Standard to index knowledge from connected applications.
</Note>
