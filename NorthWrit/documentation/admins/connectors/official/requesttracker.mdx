---
title: "Request Tracker"
description: "The Request Tracker connector is no longer available"
---

<Warning>
  NorthWrit v5 does not include a Request Tracker connector. NorthWrit removed the connector,
  which supported only the Request Tracker 4.x REST API 1.0.
</Warning>

Existing Request Tracker connectors do not run on NorthWrit v5. Delete them from **Admin Panel → Indexing Status**.

To index ticket data from another system,
see the connectors under [Ticketing & Task Management](/admins/connectors/overview#ticketing-task-management).
